**PRND Media Randomizer** сохраняет уникальность каждого публикуемого вами файла. Один десктопный инструмент рандомизирует **изображения, видео и аудио** — геометрию, цвета, накладываемые элементы, метаданные, даты и имена файлов. Идеален для массовых рассылок личных либо публичных сообщений (SMM), где одинаковые вложения приводят к ограничениям, и для охвата большей аудитории через массовые рассылки Telegram PRIME.

> Описание доступно и на других языках:
> **[EN — English](https://github.com/mediauniq/mediauniq/blob/main/README.md)** · **[ZH — 中文](https://github.com/mediauniq/mediauniq/blob/main/README_ZH.md)**

## ✨ Главное

| | |
|---|---|
| **3 медиа-модуля** | Изображения, Видео и Аудио в одном окне — у каждого свой набор рандомизации |
| **Конвертер any-to-any** | Загрузите MP3 — получите рандомизированный OGG/OPUS/M4A: форматы современных мессенджеров |
| **Уникально всё** | Случайные эффекты, перезапись EXIF/тегов, случайные даты, 5 правил именования файлов |
| **Пакетная работа** | Укажите папку — получите N копий на файл с безопасными уникальными именами |
| **Живое предпросмотр** | Проверьте образец до запуска: границы MIN/MAX, авто-предпросмотр, прослушивание с громкостью |
| **Приватность** | Вся обработка выполняется локально (FFmpeg/Pillow) — ваши файлы никуда не загружаются |
| **Мультиязычный интерфейс** | English, Русский, 简体中文 · 11 тем · настраиваемый размер шрифта и масштаб |

## 🖼️ Вкладка «Изображения»

Поддерживаемый вход: `.jpg` `.jpeg` `.png` `.tif` `.tiff`

| Функция | Описание |
|---|---|
| Случайная геометрия | масштабирование, поворот (в обе стороны), обрезка краёв, скругление углов |
| Случайный цвет | контраст, цвет/насыщенность, яркость, резкость, размытие, оттенок |
| RGB-пикселизация | случайное количество проходов |
| Качество экспорта | случайный диапазон JPEG-качества |
| Рамка | случайные цвет и толщина |
| Текст | многострочный текст, шрифт, размер, цвет / случайный цвет, положение, непрозрачность, поворот, отступы |
| Водяной знак | наложение изображения: размер, непрозрачность, поворот, отступы, 12 вариантов позиции, включая ручные X/Y в % |
| EXIF-метаданные | полная очистка или рандомизация (камера, софт, гео-позиция, ...) |
| Дата файла | случайная дата изменения |
| Пакетный режим | вход папкой, N копий на файл |
| Живой предпросмотр | рендер образца с текущими настройками, границы MIN/MAX |

## 🎬 Вкладка «Видео»

Поддерживаемый вход: `.mp4` `.mov` `.mkv` `.avi` `.webm` `.m4v` `.mpg` `.mpeg` `.ts` `.wmv` `.gif`

| Функция | Описание |
|---|---|
| Обрезка | случайный фрагмент с начала и конца |
| Движение | случайные скорость, джиттер FPS, зеркало, поворот, зум |
| Цвет | случайные яркость, контраст, насыщенность, гамма |
| Аудиодорожка | случайный диапазон громкости, заглушение |
| Текст | многострочный, шрифт, размер, непрозрачность, поворот, отступы, появление/затухание, случайное окно показа |
| Рамка | случайные цвет и толщина |
| Фон | случайный сплошной цвет или картинка с центрированным наложением |
| Метаданные | случайные MP4-теги, случайная дата файла |
| Кодирование | диапазон CRF, пресеты, аппаратное ускорение, режим потокового копирования (только метаданные) |
| GIF | анимированный GIF на входе — рандомизированный GIF на выходе |
| Предпросмотр | покадровый предпросмотр текущей цепочки фильтров |

## 🎵 Вкладка «Аудио»

Поддерживаемый вход: `.mp3` `.wav` `.ogg` `.opus` `.m4a` `.aac` `.flac` `.wma` `.aiff`
Выход: `.mp3` `.ogg` `.opus` `.m4a` `.aac` `.wav` `.flac` `.wma`

| Функция | Описание |
|---|---|
| Конвертер | любой входной формат в любой выходной (например, MP3 на входе — рандомизированный OGG на выходе для мессенджеров) |
| Скорость | случайная скорость воспроизведения |
| Тон | случайный сдвиг в полутонах, длительность сохраняется |
| Громкость | случайный диапазон громкости |
| Эквалайзер | случайные низкие / высокие частоты |
| Фейд | случайное нарастание и затухание |
| Битрейт | случайный битрейт для форматов с потерями |
| Теги | рандомизация title/artist/album/genre/date или полная очистка |
| Дата файла | случайная дата изменения |
| Прослушивание | рендер первых 10 секунд с текущими эффектами и воспроизведение — MIN/MAX, авто-режим, слайдер громкости |

## 🚀 Быстрый старт

1. Скачайте актуальный релиз, распакуйте и запустите.
2. Запросите бесплатный демо-ключ прямо в окне лицензии.
3. Выберите вкладку, укажите исходный файл или папку и папку назначения, настройте случайные диапазоны.
4. Нажмите **RANDOMIZE**.
